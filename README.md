# SZ Umbrel App Store

Community app store for [Umbrel](https://umbrel.com).

## Add it to Umbrel

App Store → ⋯ (top right) → Community App Stores → paste:

```
https://github.com/SuarezLuis/umbrel-apps
```

## Apps

- **Lanscape** (`sz-lanscape`): home network monitoring (speed tests, devices, network overview). Source: [SuarezLuis/lanscape](https://github.com/SuarezLuis/lanscape). Web UI on port 4545.
