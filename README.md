# SZ Umbrel App Store

Community app store for [Umbrel](https://umbrel.com).

## Add it to Umbrel

App Store → ⋯ (top right) → Community App Stores → paste:

```
https://github.com/SuarezLuis/umbrel-apps
```

## Apps

- **Lanscape** (`sz-lanscape`): home network monitoring (traffic, devices, bandwidth), built on ntopng. Web UI on port 4545.
